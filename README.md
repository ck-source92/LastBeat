# LastBeat

An undergraduate final project exploring dynamic difficulty adjustment in rhythm-based gameplay. 

* **Final Project Repository:** [Dinus Repository](https://repo.dinus.ac.id/items/7c673fea-3a15-426b-ad65-38a2be031ef3)

## Player Roles
* Cube
* Ship
* Robot

## Overview
LastBeat uses **Fuzzy Logic** to dynamically determine and adjust the gameplay mood/difficulty levels (Unbeat, Normal, or Upbeat). The fuzzification process evaluates two key metrics:
1. **Player Attempts:** The number of tries or failures in the game.
2. **Player Jump Inputs:** The frequency and timing of jump actions.
